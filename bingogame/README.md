# Bingo Game

Bingo Game is a web application designed to manage and display bingo draws in real time. The project includes a control page for marking drawn numbers and a public dashboard that highlights the latest 5 numbers drawn, providing a simple and dynamic experience for bingo sessions and events.

## 🚀 Tecnologias

### Frontend
- React
- Vite
- TypeScript
- Node.js
